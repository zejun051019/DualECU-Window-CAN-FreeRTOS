嵌入式软件项目 · 实体台架演示

双 ECU 车窗执行器控制原型

用两块 MCU 和带反馈的电机模拟车窗升降。点击下方播放器即可观看约 59 秒的现场视频，手机与电脑都可直接打开。

现场拍摄：开发板按键与电机动作。视频保留原有声音，可全屏观看。

控制链路

F407 按键 / FreeRTOS
↓ Classic CAN
G3507 本地门控
↓ UART 命令与反馈
X42S 电机

台架功能

  • 长按：显式恢复并建立临时零点，轴保持静止。
  • 短按：请求约 90° 上行，到上端后再按请求回程。
  • 运动中短按：中途停止，新操作才允许再次运动。

值得看源码的部分

  • FreeRTOS 的中断 → 队列 → 任务链路，以及共享状态和接收时间的处理。
  • 序号、状态确认与 STOP → CLEAR → STOP 显式恢复；发送成功与业务执行分开。
  • 执行端本地失联停止、故障锁存和有限小段运动；重连不恢复旧目标。
项目源码 架构与任务设计 验证记录
这是带驱动器的空轴电机台架，不是实车车窗。视频展示按键和电机动作；协议与故障验证的输入方式、版本和数据见项目记录。电机内部负责闭环，本项目负责跨节点请求、反馈监督与故障处理。
